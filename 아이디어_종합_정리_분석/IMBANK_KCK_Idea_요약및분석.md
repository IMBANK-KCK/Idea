## 📌 아이디어 ① — 단디의 AI 기반 ESG 공급망 금융 관리 플랫폼

**핵심 개념:** iM뱅크의 마스코트 **'단디'** 를 AI 경영 비서로 활용해, 소상공인·중소기업의 **ESG 점수를 AI가 평가하고 대출 금리를 자동으로 조절**하는 B2B 금융 플랫폼.

**파이프라인 (4단계):**
```
ESG 데이터 수집 → AI 신용 평가(Random Forest) → SHAP 기반 XAI 원인 분석 → 단디 대시보드 출력
```

| 기술 | 역할 |
|---|---|
| `Scikit-learn` | ESG 점수 기반 금리 예측 |
| `SHAP` | "왜 이 금리인가?" 설명 가능한 AI (XAI) |
| `LangChain + OpenAI` | 단디 AI 챗봇 엔진 |
| `Streamlit` | 비전공자가 만드는 시각화 대시보드 |

**핵심 포인트:**  
단순한 환경 캠페인이 아니라, 은행이 리스크를 줄이고 수익을 내면서도 ESG 가치를 실현하는 **수익성 + 법적 안전성 + 포용 금융** 3박자를 맞춘 아이디어.

- **수익성 중심**: ESG 점수가 높은 기업은 연체율이 낮아 은행의 장기 수익에 기여
- **법적 안전성**: 금융감독원 AI 가이드라인 준수 (설명 가능한 AI, XAI)
- **B2B 포용 금융**: 지역 소상공인 ESG 생태계 조성

**단디 챗봇 메시지 예시:**
> *"대표님! 이번 달 종이 영수증 발행을 40% 줄여 탄소 감축 기여율이 상승했습니다. 이대로 유지하시면 다음 달 대출 금리가 0.1%p 더 내려갑니다!"*

## 📌 아이디어 ② — 시각장애인·저시력자를 위한 금융 데이터 요약 및 음성 브리핑

**핵심 개념:** 기존 TTS는 화면의 모든 텍스트를 기계적으로 읽어줄 뿐이지만, 이 시스템은 **AI가 핵심 금융 데이터를 골라내어 자연스러운 대화체로 요약한 뒤 음성으로 브리핑**함. 배리어프리(Barrier-free) 포용 금융 서비스.

**파이프라인 (4단계):**
```
SQL 데이터 추출 → Pandas 전처리 → 자연어 문장 템플릿 매핑 → gTTS 음성 합성 및 재생
```

| 기술 | 역할 |
|---|---|
| `SQLite` | 은행 거래 데이터 추출 (SQL 쿼리) |
| `Pandas` | 지출 변화량 비교 및 핵심 정보 추출 |
| `gTTS` | 한국어 음성 파일(.mp3) 생성 |
| `Streamlit` | 오디오 재생 UI (`st.audio` 컴포넌트) |

**음성 브리핑 예시:**
> *"이번 달 배달음식 지출이 지난달보다 20만 원 더 늘었습니다. 전체 소비는 15% 단디(단단히) 늘었습니다."*

**특이점:** 실제 `.mp3` 데모 파일(`im_voice_briefing.mp3`, 약 180KB)이 레포에 포함되어 있음 — 실제로 음성을 구현해서 커밋한 것.

## 📌 아이디어 ③ — 실시간 국과수 DB 연동형 AI 보이스피싱 방어 시스템

**핵심 개념:** 사용자가 **통화 중에 iM뱅크 앱으로 송금을 시도하면** 자동으로 상대방 목소리를 3초간 분석하여, **국립과학수사연구원(국과수) DB의 범죄자 목소리와 실시간으로 대조**해 보이스피싱을 차단하는 시스템.

**파이프라인 (4단계):**
```
국과수 API 연동 + 안심 성문 등록
    → MFCC 음성 특징 추출 + 해싱 암호화
    → 실시간 3초 버퍼링 스트리밍
    → 코사인 유사도 비교 → 경고 팝업 + 송금 차단
```

| 기술 | 역할 |
|---|---|
| `MFCC` | 목소리를 "디지털 악보"로 변환하는 음성 특징 추출 |
| `PyTorch` | 성문(Voice Embedding) 딥러닝 모델 |
| `코사인 유사도` | 두 목소리 벡터의 방향이 얼마나 같은지 수학적으로 측정 |
| `데이터 해싱` | 음성 원본 없이 암호화된 특징값만 비교해 프라이버시 보호 |

**작동 조건 (트리거):**  
`사용자가 통화 중` + `iM뱅크 앱에서 송금 시도` → 두 조건이 동시에 충족될 때 자동 구동

**경고 기준:**  
국과수 DB 음성과 코사인 유사도 **90% 초과** 시 → `[위험! 국과수 등록 보이스피싱범 확정]` 팝업 + 송금 전면 차단
