# [iM금융그룹 공모전] AX 기반 배리어프리 금융 데이터 음성 브리핑 플랫폼 기획서

본 기획서는 iM금융그룹 AX추진부의 **'고객을 위한 AI'** 및 **'「inter maum」, 상생을 담은 AI'** 원칙을 실현하기 위한 프로젝트 기획서입니다. 정보 취약계층(시각장애인 및 저시력자)이 모바일 뱅킹 서비스 이용 중 겪는 금융 정보 비대칭 문제를 해결하고, 복잡한 원장 데이터를 직관적인 음성 보고서로 변환하는 배리어프리(Barrier-free) 기술 구현 방안을 다룹니다.

> **3. 시각장애인 및 저시력자를 위한 '금융 데이터 요약 및 음성 브리핑' (배리어프리)**
> 
> * **정보의 비대칭성 문제:** 기존 은행 앱의 시각장애인용 TTS(음성 읽기) 기능은 화면에 있는 모든 텍스트를 기계적으로 읽어주기만 할 뿐, 복잡한 표(이자율 변동 내역, 자산 포트폴리오 등)에 담긴 '핵심 정보'를 직관적으로 전달하지 못합니다.
> * **서비스 기획:** 단순한 텍스트 리딩을 넘어, 이번 달 지출의 가장 큰 변화나 대출 금리 변동 같은 핵심 금융 데이터를 짧은 대화형 문장으로 요약하여 음성으로 브리핑해 주는 기능입니다.
> * **기획서 구현 포인트:** 복잡한 데이터베이스(DB)의 테이블 정보를 사용자가 이해하기 쉬운 텍스트 구조로 변환하는 데이터 전처리 역량이 중요합니다. SQL로 필요한 데이터를 빠르고 정확하게 추출한 뒤, 이를 자연스러운 문장 템플릿에 매핑하는 백엔드 처리 과정을 강조할 수 있습니다.

## 2. iM금융그룹 AX 핵심 가치와의 연계성

* **상생을 담은 AI (「inter maum」)**: 단순한 고효율 비즈니스에만 집착하는 AI가 아니라, 장애인과 고령층 등 디지털 금융 소외 계층을 감싸 안는 포용 금융을 실천합니다.
* **고객의 니즈를 사로잡는 AI**: 사용자가 복잡한 금융 수치나 빽빽한 이자율 표를 보고 직접 해독할 필요 없이, AI가 비서처럼 핵심 변동 사항만 콕 집어 설명해 주어 실질적인 금융 편의성을 높입니다.

## 3. 권장 기술 스택 및 개발 환경 (Development Environment)

비전공자 팀원들이 손쉽게 데이터를 관리하고, 한두 줄의 파이썬 코드로 텍스트를 실제 한국어 음성 파일(`.mp3`)로 바꾸어 재생해 볼 수 있는 최고의 도구 조합입니다.

| 구분 | 추천 기술 및 라이브러리 | 선정 이유 |
| :--- | :--- | :--- |
| **개발 언어** | **Python (파이썬)** | 풍부한 데이터 전처리 및 인공지능 음성 변환 패키지를 제공하는 대중적인 언어입니다. |
| **데이터베이스** | **SQLite** | 별도의 복잡한 서버 구축 없이 파이썬 내장 라이브러리로 즉시 SQL 질의(Query) 실습을 해볼 수 있는 경량 DB입니다. |
| **데이터 전처리** | **Pandas (판다스)** | 데이터베이스에서 추출한 금융 자산 및 지출 내역 표(Table) 데이터를 요약·비교하는 데 탁월한 라이브러리입니다. |
| **음성 합성 (TTS)** | **gTTS (Google Text-to-Speech)** | 복잡한 딥러닝 학습 없이 **오직 3~4줄의 코드만으로** 자연스러운 한국어 목소리 음성 파일을 구워내는 라이브러리입니다. |
| **프로토타입 화면** | **Streamlit (스트림릿)** | 오디오 재생 컴포넌트(`st.audio`)를 기본 지원하여, 생성된 음성 브리핑 파일을 사용자가 마우스로 클릭해 들어볼 수 있게 해주는 도구입니다. |

## 4. 금융 데이터 음성 브리핑 개발 파이프라인 (4-Step Pipeline)

복잡한 은행 장부 데이터가 시각장애인 고객의 귀에 쏙 들어오는 따뜻한 목소리로 전달되기까지의 가공 파이프라인입니다.


```
[1단계: SQL 데이터 추출] ➔ [2단계: Pandas 데이터 전처리] ➔ [3단계: 문장 템플릿 맵핑/요약] ➔ [4단계: gTTS 음성 합성 및 UI 출력]
```

### 1단계. SQL 핵심 데이터 추출 (Data Extraction)
* **목적**: 수천만 개의 은행 거래 원장 중에서 사용자의 최근 지출 내역과 금융 상품 이자 변동 표 데이터를 빠르게 가져옵니다.
* **구현**: 관계형 데이터베이스(RDB)에 접근하여 필요한 시점(예: 최근 1개월)의 데이터만 콕 집어내는 SQL 쿼리문을 실행합니다.
  ```sql
  -- 예시: 해당 사용자의 이번 달 카테고리별 지출 합계를 큰 순서대로 가져오는 SQL
  SELECT category, SUM(amount) AS total_spend
  FROM user_transactions
  WHERE user_id = 'im_user_01' AND date >= '2026-07-01'
  GROUP BY category
  ORDER BY total_spend DESC;
  ```

### 2단계. 데이터 전처리 및 핵심 정보 비교 (Data Preprocessing)
* **목적**: 기계적인 숫자 나열을 피하기 위해 데이터를 가공 및 비교 분석합니다.
* **구현**: 파이썬 `Pandas` 라이브러리를 사용해 '지난달 평균 지출액'과 '이번 달 지출액'의 차이를 계산하고, 가장 소비가 크게 늘어난 카테고리를 찾아냅니다.
* **예시**: *"이번 달 총지출액은 150만 원으로 지난달 대비 15% 증가했으며, 배달음식 지출이 20만 원으로 가장 큰 상승 폭을 보임"*

### 3단계. 자연스러운 문장 템플릿 맵핑 (NLG - Natural Language Generation)
* **목적**: 분석된 차이 데이터를 시각장애인 고객이 듣고 바로 이해할 수 있는 친근한 일상 대화문 형태로 변환합니다.
* **구현**: 복잡한 표 레이아웃 대신, 미리 짜놓은 한국어 자연어 템플릿에 데이터 변수를 매핑(Mapping)하거나 OpenAI API를 활용해 대화용 요약 문장을 자동 생성합니다.
* **템플릿 예시**: *"대표님(고객님), 이번 달에는 [배달음식] 지출이 지난달보다 [20만 원] 더 늘어난 것이 특징입니다. 전체 소비는 지난달보다 [15%] 단디(단단히) 늘었습니다."*

### 4단계. 음성 합성 및 오디오 출력 (TTS & Audio Playback)
* **목적**: 요약 완료된 대화형 텍스트를 부드럽고 가청성 높은 소리 음성으로 변환하여 기기에 재생합니다.
* **구현**: 파이썬 `gTTS` 라이브러리로 생성된 텍스트를 한국어 음성 주파수 데이터로 합성하여 `.mp3` 파일로 저장한 후, 웹/앱 화면(`Streamlit` 또는 스마트폰 화면)에서 오디오 플레이어 버튼을 통해 출력합니다.

## 5. 처음 배우는 비전공자를 위한 핵심 기술 용어 해설

### 💡 배리어프리 (Barrier-free)
* **공식 정의**: 고령자나 장애인들도 살기 좋은 사회를 만들기 위해 물리적·제도적·장벽(Barrier)을 허물자는 취지에서 시작된 운동으로, IT 분야에서는 정보 취약계층이 디지털 서비스를 차별 없이 이용할 수 있게 보장하는 정보 접근성을 의미합니다.
* **비전공자용 풀이**: 몸이 불편하거나 눈이 잘 보이지 않는 분들이 스마트폰 뱅킹 앱을 사용할 때 부딪히는 **'이용 장벽(불편함)을 허물어 모두가 평등하게 쓸 수 있도록 기술로 도와주는 따뜻한 상생 활동'**입니다.

### 💡 SQL (Structured Query Language)
* **공식 정의**: 관계형 데이터베이스 관리 시스템(RDBMS)의 데이터를 관리하기 위해 설계된 표준화된 컴퓨터 프로그래밍 언어로, 데이터의 검색, 삽입, 수정, 삭제 등의 작업을 제어하는 데 사용됩니다.
* **비전공자용 풀이**: 컴퓨터가 가지고 있는 거대한 데이터 보관 창고(Database)에서 내가 원하는 상자만 콕 집어 가져오기 위해 **컴퓨터에게 보내는 '검색 및 데이터 배달 요청 명령문'**입니다.

### 💡 데이터 전처리 (Data Preprocessing)
* **공식 정의**: 수집된 가공되지 않은 상태의 가공 원시 데이터(Raw Data)를 모델 학습이나 분석 목적에 적합하도록 정제(Cleaning), 가치 필터링, 데이터 형식 변환 및 누락값(Null) 처리 등을 수행하는 데이터 엔지니어링의 핵심 과정입니다.
* **비전공자용 풀이**: 밭에서 갓 수확해 흙이 잔뜩 묻어 있는 감자(원시 데이터)를 요리하기 좋게 **'물로 깨끗이 씻고 껍질을 까서 먹기 좋은 크기로 썰어내는 요리 준비 과정'**입니다.

### 💡 TTS (Text-to-Speech, 음성 합성)
* **공식 정의**: 인공적으로 사람의 음성을 합성하여 텍스트 정보를 소리 신호(음성 데이터)로 변환하여 출력하는 기술 및 시스템을 의미합니다.
* **비전공자용 풀이**: 화면에 적힌 **'글자(Text)'**를 스마트폰이나 컴퓨터가 사람처럼 자연스럽게 **'목소리 소리(Speech)'**로 읽어 주는 오디오 변환 기술입니다.
